Τελευταία ενημέρωση: 5 Οκτωβρίου 2026
{ .muted }

Έχετε δικαίωμα να ζητήσετε τη διαγραφή των προσωπικών σας δεδομένων (άρθρο 17 του Γενικού Κανονισμού Προστασίας Δεδομένων, ΓΚΠΔ). Εδώ εξηγούμε πώς, τι διαγράφεται, και τι κρατάμε κατ' εξαίρεση επειδή μας το επιβάλλει ο νόμος.

## Διαγραφή μόνοι σας (άμεσα) { #amesa }

1. Συνδεθείτε και ανοίξτε τη σελίδα [Ο λογαριασμός μου]({{root}}account/#delete).
2. Στο τέλος της σελίδας πατήστε **«Διαγραφή λογαριασμού»** και επιβεβαιώστε.

Για λόγους ασφαλείας μπορεί να σας ζητηθεί να συνδεθείτε ξανά πριν από τη διαγραφή. Η διαγραφή είναι οριστική και δεν αναιρείται.

### Τι διαγράφεται { #ti-diagrafetai }

Αμέσως και οριστικά διαγράφονται:

- ο λογαριασμός σύνδεσης (όνομα, e-mail, φωτογραφία προφίλ, τρόποι σύνδεσης),
- η αίτηση μέλους σας και όλα τα στοιχεία της,
- η καταχώρισή σας στον κατάλογο μελών,
- οι ειδοποιήσεις με e-mail που είχατε επιλέξει,
<!--if:linkedin-->
- η εγγραφή που συνδέει τον λογαριασμό σας με το LinkedIn, αν υπήρχε,
<!--/if:linkedin-->
- τα μηνύματα που μας στείλατε από τη σελίδα «Σχόλια και προβλήματα», μαζί με τα στιγμιότυπα οθόνης.

Το αντίγραφο των μηνυμάτων σας στο ιδιωτικό μας αποθετήριο στο GitHub αφαιρείται στον επόμενο συγχρονισμό, μέσα σε λίγη ώρα.

## Διαγραφή με e-mail { #email }

Αν δεν μπορείτε να συνδεθείτε, στείλτε e-mail στο [gradsemfe@gmail.com](mailto:gradsemfe@gmail.com?subject=%CE%94%CE%B9%CE%B1%CE%B3%CF%81%CE%B1%CF%86%CE%AE%20%CE%B4%CE%B5%CE%B4%CE%BF%CE%BC%CE%AD%CE%BD%CF%89%CE%BD) με θέμα «Διαγραφή δεδομένων» από τη διεύθυνση του λογαριασμού σας. Θα διαγράψουμε τα δεδομένα σας χωρίς αδικαιολόγητη καθυστέρηση και το αργότερο μέσα σε έναν μήνα από τη λήψη του αιτήματος, και θα σας το επιβεβαιώσουμε. Αν γράψετε από άλλη διεύθυνση, μπορεί να σας ζητήσουμε στοιχεία για να βεβαιωθούμε ότι είστε εσείς· δεν θα σας ζητήσουμε περισσότερα από όσα χρειάζονται.

Με τον ίδιο τρόπο μπορείτε να ζητήσετε να διαγραφούν και όσα δεν διαγράφονται αυτόματα, όπως τα e-mail που έχουμε ανταλλάξει.

## Τι κρατάμε κατ' εξαίρεση { #exaireseis }

Ο νόμος (άρθρο 17 παρ. 3 ΓΚΠΔ) επιτρέπει, και σε ορισμένες περιπτώσεις επιβάλλει, να κρατήσουμε κάποια στοιχεία και μετά τη διαγραφή. Κρατάμε μόνο τα απαραίτητα και μόνο όσο χρειάζεται:

- **Οικονομικά και λογιστικά στοιχεία** για συνδρομές και δωρεές, όσο ορίζει η λογιστική και φορολογική νομοθεσία (κατά κανόνα πέντε έτη από το τέλος του έτους στο οποίο αφορούν).
- **Μητρώο μελών:** αν έχετε υπάρξει μέλος, ο Σύλλογος μπορεί να διατηρήσει μόνο τα ελάχιστα στοιχεία που αποδεικνύουν την ιδιότητά σας και τη συμμετοχή σας στα όργανα και στις ψηφοφορίες του (π.χ. ονοματεπώνυμο και διάστημα ιδιότητας μέλους), όσο το απαιτεί η λειτουργία του ως σωματείου.
- **Αρχείο ενώσεων λογαριασμών:** αν ο λογαριασμός σας είχε ενωθεί ποτέ με άλλον, η σχετική καταγραφή (ποιοι λογαριασμοί, ονόματα, e-mail, πότε) μένει για λόγους ασφάλειας και λογοδοσίας, μέχρι να μη χρειάζεται ή μέχρι να μας ζητήσετε να τη διαγράψουμε.
- **Αλληλογραφία:** τα e-mail που έχουμε ανταλλάξει μένουν στο γραμματοκιβώτιο του Συλλόγου και των διαχειριστών, και παλαιότερες εκδοχές των μηνυμάτων σας μπορεί να μένουν στο ιστορικό του ιδιωτικού μας αποθετηρίου. Τα διαγράφουμε αν μας το ζητήσετε.
- **Στοιχεία για νομικές αξιώσεις:** όσα χρειάζονται για τη θεμελίωση, την άσκηση ή την υπεράσπιση νομικών αξιώσεων, μέχρι να λήξει η διαφορά ή να παραγραφούν.
- **Αντίγραφα ασφαλείας και τεχνικά αρχεία καταγραφής των παρόχων μας** (Google, GitHub): για περιορισμένο διάστημα, μέχρι να αντικατασταθούν, χωρίς να χρησιμοποιούνται για κανέναν άλλο σκοπό.

Τα **ανώνυμα στατιστικά** (π.χ. «12 μέλη στην Αθήνα») δεν αφορούν πρόσωπα και δεν αλλάζουν όταν διαγράφετε τον λογαριασμό σας.

## Θέλετε μόνο να σταματήσετε κάτι; { #merika }

Δεν χρειάζεται να διαγράψετε όλο τον λογαριασμό σας για να:

- **σταματήσετε τις ειδοποιήσεις με e-mail:** πατήστε τον σύνδεσμο στο τέλος κάθε e-mail ή αλλάξτε τις [επιλογές σας]({{root}}account/#alerts),
- **σταματήσετε το newsletter ή τις ανακοινώσεις θέσεων εργασίας:** βγάλτε την επιλογή στην αίτηση μέλους, από τον [λογαριασμό σας]({{root}}account/),
- **βγείτε από τον κατάλογο μελών:** αποσύρετε το προφίλ σας από τον [λογαριασμό σας]({{root}}account/),
- **διορθώσετε ή σβήσετε κάποιο στοιχείο:** αλλάξτε το στην αίτηση μέλους,
- **μη μετράμε τις επισκέψεις σας:** ενεργοποιήστε στον browser σας το Global Privacy Control ή το Do Not Track.

## Αποχώρηση από τον Σύλλογο { #apoxorisi }

Η διαγραφή του λογαριασμού σας διαγράφει τα στοιχεία σας από τον ιστότοπο. Αν θέλετε να αποχωρήσετε και από τον Σύλλογο ως μέλος, ενημερώστε το Διοικητικό Συμβούλιο στο [gradsemfe@gmail.com](mailto:gradsemfe@gmail.com). Σύμφωνα με το άρθρο 7 του [Καταστατικού]({{root}}assets/docs/foundation/katastatiko.pdf){ newtab }, οι εισφορές που έχουν καταβληθεί δεν επιστρέφονται.

## Αφαίρεση φωτογραφίας ή αναφοράς σας { #afairesi }

Οι φωτογραφίες από εκδηλώσεις, τα ονόματα σε ανακοινώσεις και τα έγγραφα του αρχείου δεν συνδέονται με τον λογαριασμό σας, και γι' αυτό δεν διαγράφονται μαζί του. Αν εμφανίζεστε ή αναφέρεστε κάπου στον ιστότοπο και θέλετε να αφαιρεθείτε, γράψτε μας στο [gradsemfe@gmail.com](mailto:gradsemfe@gmail.com) με τη διεύθυνση της σελίδας. Θα αφαιρέσουμε ή θα θολώσουμε τη φωτογραφία ή το όνομά σας χωρίς αδικαιολόγητη καθυστέρηση, εκτός αν υπάρχει σοβαρός λόγος να μείνει (π.χ. έγγραφο που ο Σύλλογος πρέπει να τηρεί), οπότε θα σας εξηγήσουμε γιατί.

## Αν συνδεθήκατε με {{signin-social}} { #paroxos }

Η διαγραφή εδώ διαγράφει τα δεδομένα που κρατάμε εμείς. Για να αφαιρέσετε και την πρόσβαση της εφαρμογής από τον λογαριασμό σας στον πάροχο:

<!--if:google-->
- **Google:** [Συνδέσεις του λογαριασμού σας Google](https://myaccount.google.com/connections){ newtab } → επιλέξτε την εφαρμογή → Διαγραφή συνδέσεων.
<!--/if:google-->
<!--if:linkedin-->
- **LinkedIn:** Ρυθμίσεις → Απόρρητο δεδομένων → Επιτρεπόμενες υπηρεσίες (Permitted services) → Κατάργηση.
<!--/if:linkedin-->
<!--if:facebook-->
- **Facebook:** Ρυθμίσεις και απόρρητο → Ρυθμίσεις → Εφαρμογές και ιστότοποι → επιλέξτε την εφαρμογή του Συλλόγου → Κατάργηση.
<!--/if:facebook-->

Τα δεδομένα που κρατά ο ίδιος ο πάροχος για εσάς διέπονται από τη δική του πολιτική απορρήτου.
